# Погадай.Ру — Астрологический сайт

Магический гороскоп, камни-талисманы и тотемные животные

## О проекте
Сайт для любителей астрологии с:
- Персональным гороскопом по знаку зодиака
- Совместимостью между знаками
- Камнями души — подбором талисманов
- Восточным гороскопом по году рождения
- Тотемными животными-покровителями

## Технологии
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Backend: Node.js + Express
- Стиль: Адаптивный дизайн (mobile-friendly)
- API: REST для данных гороскопов

## Запуск проекта
1. Склонируйте репозиторий.

2. Установите зависимости:
cd backend
npm install

3. Запустите сервер:
npm start

4. Откройте в браузере:
http://localhost:3002

### Главная страница
